# RED FOX — PHOENIX CONTROL

Главная оболочка Safari-игры «Объект ФЕНИКС» для RED FOX Quest.

## Назначение

Скрипт преобразует стандартную страницу списка заданий RED FOX в тематический интерфейс секретного объекта:

- шапка PHOENIX CONTROL;
- название игры и команды;
- таймер RED FOX до окончания игры;
- схематическая карта секторов и переходами к заданиям;
- список заданий с прогрессом найденных кодов;
- адаптивная компоновка для мобильных экранов.

## Текущий статус

Версия 0.1.0 — первый каркас оболочки. Скрипт читает существующие элементы страницы RED FOX и не подменяет серверную проверку кодов.

## Подключение

После проверки тестовой версии скрипт подключается в HTML-поле названия игры:

```html
<script src="https://cdn.jsdelivr.net/gh/RedLine142/redfox-phoenix-control@main/redfox-phoenix-control.js"></script>
```

## Источники данных

- `.container` — контейнер списка;
- `.team_name` — название команды;
- `h1` — название игры;
- `.item a[href]` — ссылки на задания;
- `.item strong` — название задания;
- текст внутри `.item` в формате «найдено / всего» — прогресс;
- `.time #time_left` — таймер до окончания игры;
- `.time #timer` — локальные часы.

## Ограничения первой версии

- Карта строится автоматически из фактического списка заданий и пока является схематической навигацией, а не точным планом помещений.
- Статус завершения вычисляется по найденным и общим кодам.
- Таймер показывает значение, которое рассчитывает RED FOX.
- Скрипт не вмешивается в отправку кодов и серверный учёт результатов.
- Перед использованием в действующей игре необходимо проверить страницу на компьютере и телефоне.
